# NexaChat

Primeira versão do aplicativo de mensagens.

## Render
Build/Install: npm install
Start: npm start

O projeto já possui:
- interface mobile
- servidor Node.js/Express
- Socket.IO
- mensagens em tempo real
- endpoint /api/status

Próximas etapas:
cadastro/login, usuários por número, PostgreSQL, contatos, conversas privadas e segurança.
